# Universal Consultant

Диалоговый консультант помогает разобраться в товарах и услугах, собрать заказ или назначить встречу и оформить запись после явного согласия клиента.

Система универсальна: один и тот же набор инструмент позволяет консультировать в любом домене. Для нового заказчика достаточно загрузить данные.

## Начало работы

```bash
uv sync
uv run pre-commit install
```

Проверки вручную:

```bash
uv run ruff check .
uv run ruff format .
uv run pre-commit run --all-files
```

`ruff check` ищет ошибки, `ruff format` выравнивает стиль. Перед коммитом pre-commit запускает оба хука: линтер с автоисправлением, затем форматер. Конфигурация Ruff лежит в `pyproject.toml`, хуки — в `.pre-commit-config.yaml`.
