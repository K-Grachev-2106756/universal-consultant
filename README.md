# Universal Consultant

Диалоговый консультант помогает разобраться в товарах и услугах, собрать заказ или назначить встречу и оформить запись после явного согласия клиента.

Система универсальна: один и тот же набор инструмент позволяет консультировать в любом домене. Для нового заказчика достаточно загрузить данные.
